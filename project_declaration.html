项目定位

MoonGraph 为 MoonBit 生态提供可复用的泛型 Graph[N, E] 邻接表、节点/边安全检查、遍历、路径规划、连通性分析、依赖调度、网络流、匹配和 Graphviz DOT 导出能力。适用场景包括编译器依赖解析、构建系统、网络拓扑、路径规划、课程实验和图数据分析。

本次验收版本的功能范围

  • 基础结构：有向图/无向图、泛型节点与边权重、节点与边索引、度数和邻接查询。
  • 遍历与结构分析：BFS、DFS、环检测、Tarjan SCC、弱连通分量、传递闭包、割点、桥、贪心着色。
  • 路径与调度：Dijkstra、A*、Bellman–Ford、可重建最短路径、Floyd–Warshall、拓扑排序、拓扑分层、DAG 最长路。
  • 网络算法：Kruskal/Prim 最小生成树或森林、Edmonds–Karp 最大流、二分图最大匹配、Euler 路径。
  • 工程支持：PriorityQueue、DisjointSet、Graphviz DOT 导出、独立 cmd/demo 示例和跨平台 CI。

可复现验证

moon version --all
moon fmt
moon check --target all --deny-warn
moon test --target all --deny-warn
moon info
moon run cmd/demo --target wasm-gc

验收版本实测包含 23 个 MoonBit 源文件、1,964 行代码（含测试）和 22 个自动化测试。CI 使用官方 latest 稳定工具链（本次验收时为 MoonBit 0.10.4），在 Ubuntu、macOS、Windows 三个平台执行检查与测试。

安装与调用

moon add wedarp/moongraph

库包路径为 wedarp/moongraph/src。仓库中的 cmd/demo 可独立运行，展示图构建、BFS、Dijkstra、拓扑排序和 DOT 输出。
